# DESIGN-AND-SIMULATION-OF-PLASMA-INTERACTION-IN-HYBRID-ROCKET-COMBUSTION-
Design and CFD validation of a plasma-assisted hybrid rocket thrust chamber. The project integrates hybrid rocket propulsion theory, RPA-4 thermochemical analysis, SolidWorks CAD modelling, and ANSYS CFD to investigate nanosecond pulsed plasma for ignition and combustion enhancement.
